# REDUX · Field report template

**Scope:** project/department, canonical owner, REDUX identity/version, date.

**Files:** `source.md` SHA256 `[hash]`, 64,001 lines, N chunks; X verified / N total; status COMPLETE/PARTIAL/BLOCKED; persistent source+manifest links or unavailable.

**Delta:** N facts/events extracted, N already present, N added, N enriched, N corrected, N conflicts, N not written.

**Actual changes:** Notion record URLs/IDs and concise verified updates. **No-change proofs** when applicable.

**Owner impact:** suggested edits to active `Quien Soy`/strategy, separated from already-applied factual records.

**Unresolved:** exact file/chunk/line range, conflicting claims, missing evidence, unavailable connector, unverifiable source.

**Succession:** next unverified chunk(s), pending transaction, REDUX `_HANDOFF` location, source/manifest durability, current agent version and date.

Never present `prepared chunks` or `model summary` as a completed audit.
